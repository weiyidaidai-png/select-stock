# A股股票均线差异筛选工具

一个基于Python和Flask的A股股票筛选工具，使用tushare数据获取股票行情，计算长期均值和短期均值的差异，筛选出差异明显的股票，并提供Web界面展示结果和价格走势图。

## 功能特点

- 📊 **数据获取**：获取全部A股股票列表和前复权日线行情
- 📈 **均值计算**：支持自定义长期均值周期和短期5日均线
- 🔍 **智能筛选**：按差异百分比阈值筛选股票，结果按差异从大到小排序
- 🎯 **行业筛选**：支持申万一级行业分类（28类）的"筛选前"和"筛选后"双重过滤
- 📊 **指数筛选**：新增！支持上证指数50、沪深300、中证500、中证1000等指数成分股预筛选
- 🔄 **预筛选功能**：新增！指数与行业的"且"逻辑预过滤，减少计算量提升性能
- 📊 **筛选统计**：新增！实时显示预筛选前后的股票数量变化
- 📱 **Web界面**：响应式设计，支持查看筛选结果和价格走势图
- ⚡ **性能优化**：API调用频率控制，数据缓存机制
- 🛡️ **错误处理**：完善的异常处理和用户友好提示

## 新增功能详解

### 🔄 预筛选功能

系统现在支持在正式筛选前进行双重预过滤：

**A. 指数分类筛选**
- 支持勾选多个指数：上证指数50、沪深300、中证500、中证1000
- 仅分析选中指数的成分股

**B. 行业分类筛选（申万一级行业28类）**
- 提供完整的申万一级行业列表
- 支持勾选多个行业
- 仅分析选中行业的股票

**C. 筛选逻辑关系**
- 指数分类与行业分类之间为"且（AND）"逻辑关系
- 股票必须同时满足指数和行业条件才会被纳入分析

**D. 预筛选结果回报**
- 筛选前的总股票数量
- 用户选择后的剩余股票数量
- 让用户清楚了解数据范围的缩小情况

## 安装和配置

### 1. 安装依赖

```bash
# 安装所需的Python库
pip install flask pandas tushare requests python-dateutil numpy
```

### 2. 配置tushare API token

1. 访问 [tushare.pro](https://tushare.pro/register) 免费注册账号
2. 登录后在个人中心获取API token

### 3. 修改配置文件

```python
# config.py
TUSHARE_TOKEN = 'your_token_here'  # 替换为你的tushare token
```

## 使用方法

### 1. 启动应用

```bash
python app.py
```

### 2. 访问应用

在浏览器中访问 `http://localhost:5000`

### 3. 设置筛选参数

**基础参数设置：**
- 长期周期：选择长期均线的时间周期
- 长期周期单位：天、月、年
- 短期周期：选择短期均线的时间周期（默认5天）
- 短期周期单位：天、月
- 差异阈值：设置筛选的差异百分比阈值（大于此值的股票将被筛选出来）

**预筛选设置：**

**📊 指数预筛选：**
- 勾选一个或多个指数（上证指数50、沪深300、中证500、中证1000）
- 系统将仅分析选中指数的成分股

**🎯 行业预筛选：**
- 勾选一个或多个行业（申万一级行业28类）
- 系统将仅分析选中行业的股票

**注意：** 指数和行业筛选为"且"关系，股票必须同时满足两个条件

### 4. 开始分析

点击"开始筛选"按钮启动分析过程

### 5. 查看结果

- 预筛选统计：显示原始股票数量和筛选后的股票数量
- 分析进度：实时显示分析进度百分比
- 结果预览：分析完成后显示前20名股票
- 完整结果：点击"查看完整结果"获取所有符合条件的股票
- 行业统计：查看各行业的股票分布情况
- 股票详情：点击股票查看价格走势图

## 使用示例

### 示例1：筛选沪深300指数中的科技类股票

**预筛选设置：**
- 指数：勾选"沪深300"
- 行业：勾选"电子"、"计算机"、"通信"、"传媒"

**基础参数：**
- 长期周期：60天
- 短期周期：5天
- 差异阈值：5%

**预期结果：**
- 系统将从沪深300指数成分股中筛选出属于科技类行业的股票
- 仅对这些股票进行均线差异分析
- 最终筛选出短期均线比长期均线高5%以上的股票

### 示例2：筛选中证500指数中的医药和消费类股票

**预筛选设置：**
- 指数：勾选"中证500"
- 行业：勾选"医药生物"、"食品饮料"

**基础参数：**
- 长期周期：120天
- 短期周期：10天
- 差异阈值：8%

**预期结果：**
- 系统将从所有A股中筛选出同时满足以下条件的股票：
  1. 属于中证500指数成分股
  2. 属于医药生物或食品饮料行业
- 对筛选后的股票计算120天和10天均线差异
- 最终返回差异大于8%的股票

## 性能优化

通过预筛选功能，可以显著减少需要分析的股票数量：

- **无预筛选：** 约4000+只股票 → 完整分析需要约10-15分钟
- **指数预筛选：** 沪深300成分股约300只 → 分析时间约1-2分钟
- **指数+行业预筛选：** 例如沪深300中的金融行业约50只 → 分析时间约10-30秒
